angular.json
Controls the Angular project configuration like build, serve, assets, styles, and scripts.

tsconfig.json
Main TypeScript configuration file used by the project.

tsconfig.app.json
TypeScript configuration specifically for the Angular application.

package.json
Contains project information, dependencies, scripts, and package versions.

src/main.ts
Entry point of the Angular application. It starts the application.

src/app/app.ts
Root component of the application.

src/app/app.config.ts
Contains application-wide configuration such as routing and providers.

src/index.html
The main HTML page where the Angular application is loaded.
